    # Kho hàng Số lượng đơn

    ⚡ Chạy Online 100% bằng Script trực tiếp trên Lark Base

    💡 Giải pháp chạy Online hoạt động như thế nào?
    Bạn không cần tải Excel hay cài đặt phần mềm nào trên máy tính. Bạn chỉ cần mở bảng Lark Base của bạn, kích hoạt tính năng Script (Kịch bản) có sẵn của Lark, dán đoạn code dưới đây vào và bấm chạy. Báo cáo dạng văn bản sẽ được in ra màn hình ngay lập tức!
    1

    Mở tiện ích Script trên Lark Base

    Truy cập file Lark Base của bạn. Trên thanh tiêu đề bên phải, bấm vào nút Extensions (Mở rộng) (hoặc dấu cộng + ở thanh công cụ bên phải) → chọn Script (Kịch bản).

    2

    Tạo Kịch bản mới và Dán code

    Bấm Tạo kịch bản mới (New script). Xóa toàn bộ đoạn code mặc định có sẵn trong khung biên tập và dán đoạn mã bên dưới vào.

    3

    Lọc dữ liệu trên View hiện tại và Chạy

    Lọc bảng dữ liệu của bạn trên View hiện tại (ví dụ: lọc theo tuần hoặc theo ngày tùy ý). Kịch bản sẽ tự động chỉ quét các dữ liệu đang hiển thị trên View đó. Sau đó bấm Chạy (Run) ở góc dưới. Kết quả báo cáo sẽ hiện ra ngay bên tay phải.

    Script dùng chung cách tính và các tuỳ chỉnh (lời mở đầu, số kho/lý do hiển thị) với trang này. Đổi tuỳ chỉnh xong thì copy lại code.
